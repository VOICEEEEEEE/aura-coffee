# ☕ AURA Specialty Coffee Roasters

Современный интерактивный веб-сайт для премиальной спешелти кофейни третьей волны и микро-обжарочной станции.
Разработан в среде **Google Antigravity** в рамках режима мультиагентной координации **`/swarm`**.

---

## 🐝 Роли агентов Swarm в разработке

1. **Lead Architect & System Designer (Gemini Carbon)**
   - Проектирование компонентной архитектуры, моделей данных меню, каталога микролотов и состояния корзины.
   - Управление циклом разработки и согласованностью интерфейса.

2. **Creative Director & Specialty Barista**
   - Брендинг и нейминг: *AURA Specialty Roasters*.
   - Тексты и дескрипторы вкуса по шкале SCA (Specialty Coffee Association).
   - Подбор аутентичных вкусовых колес (персик, жасмин, бергамот, черная смородина, маракуйя).

3. **UI/UX & Visual Designer (Warm Roast & Scandinavian Minimal)**
   - Палитра: эспрессо `#1A120B`, теплая карамель/обжарка `#D97736`, молочный шелк `#FAF7F2`.
   - Поддержка темного режима (*Dark Roast Mode*) и светлого (*Warm Milk Mode*).
   - Микро-интеракции, стеклянные панели (glassmorphism), плавные тени и отсутствие layout-сдвигов.
   - Векторные SVG-иконки Lucide (без использования смайликов/эмодзи в UI-элементах).

4. **Frontend & Interactive Features Engineer**
   - **Интерактивный тест подбора вкуса («Кофе-сомелье»)**: 3-шаговый мастер с выдачей точного микролота, рецепта и возможностью добавить зерно в корзину.
   - **Фильтруемое меню с живым поиском**: фильтрация по категориям (Фильтр, Эспрессо, С молоком, Зерно 250г, Выпечка) и мгновенный текстовый поиск с обработкой состояния «Ничего не найдено».
   - **Калькулятор заваривания V60 с живым секундомером**: автоматический пересчет граммовки и пропорций воды (1:15, 1:16, 1:17) с пошаговыми фазами пролива (Bloom, первый пролив, финал).
   - **Корзина заказов (Slide-out Drawer)**: добавление, изменение количества, расчет скидки по промокодам (`AURA10`, `SPECIALTY20`), модальное окно успешного заказа с генерацией трек-номера.
   - **Бронирование столика и открытого каппинга**: валидация формы, имитация отправки и подтверждение.
   - **Toast Notifications**: всплывающие системные уведомления.

5. **QA & Accessibility Auditor**
   - Минимальный размер интерактивных областей: 44×44px (`.btn-touch`).
   - Контрастность текста в обоих режимах (светлый/темный) согласно рекомендациям WCAG.
   - Семантическая верстка (`<header>`, `<main>`, `<section>`, `<footer>`, `<aside>`).

## 🚀 Как запустить

### Вариант 1: Запуск встроенного веб-сервера (Python)
В терминале перейдите в папку проекта и выполните:
```bash
python server.py
```
Сервер запустится на `http://localhost:3000` и автоматически откроет страницу в браузере.

### Вариант 2: Прямое открытие файла
Просто откройте файл `index.html` двойным кликом в любом браузере (Chrome, Edge, Safari, Firefox).
